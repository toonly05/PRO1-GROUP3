# PRO1-GROUP3
## IDÉ
  - Ett antal sensorer avläser när bipasserande barn korsar ett övergångsställe, samlar informationen under en längre period och kan reglera tidsramen för vilken väg hastighet som gäller i det området under dagen.
  - En sensor som mäter trafikanters egentliga hastighet och förvarnar passerande om hur fort det egentligen körs vid tillfällen under dagen.
## målgrupp

-  fordonsförare
  
- fotgängare 
## SYFTE

- Uppemärksamma trafikanter när fotgängare eller cyklister korsar övergångstället
  
- Göra trafiken mer säker för både trafikanter och icke trafikanter
## LÖSNING
  - sensorer som känner av frekvensen av antalet passerande fotgängare
  -  en strobljus som blinkar mer frekvent beroende på hur många som står vid övergångstället
