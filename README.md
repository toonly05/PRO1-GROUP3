# PRO1-GROUP3
## IDÉ
  - En temperatursensor, luftfuktighetssensor och markfuktighetssensor samlar data om dess omgivning. Den avgör om det är dimma (synlighet), vädret och vägkvalitén och hurvida det är halkigt eller inte. 
 - Utifrån det skickar den den datan till användrens mobil/dator och upplyser eller varnar hur vägförhållandet är. Syftet är att hålla användaren säker på vägen och minska chansen för en olycka. 
 - Prototypen ska då kunna: Samla data om dess omgivning och ge aktuell information, analysera datan och bygga en databas på hur vägförhållanden förändras med tiden. Den ska kunna skicka en notis en passande tid efter väckarklockslarm slår om hur vägen ser ut idag och vad hen bör tänka på.   
## målgrupp

-  fordonsförare
  
## SYFTE

- Förvarna användaren för hur vägförhållandet kan bli inom dagen eller kommande dagar så det kan adaptera sig för hur försiktig de ska vara och vad de bör tänka på.
